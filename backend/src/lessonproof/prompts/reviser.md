# Your job

An independent evaluator rejected this lesson. Fix every failed check while keeping everything that already works.

- Do not shorten the lesson. Fixes usually need more words, not fewer.
- Return only what must change. `section_updates` holds complete replacement text for the sections you change. Sections you leave out stay exactly as they are, so do not rewrite passing sections without a reason.
- Set `key_terms` or `quiz` only if they need changes, and then give the full new list. Otherwise leave them null.
- A failed check may list exact sentences or words as evidence. Fix each one, and look for the same problem elsewhere in the lesson.
- Do not break checks that passed. Stay within the fact sheet. Do not add facts to make the lesson sound stronger.
- When you simplify, the definition must stay true. Never rename a technical idea as something it is not. Keep the correct definition, then add a comparison marked with words like "think of it like".
- `change_notes` must have one entry for each failed check, saying exactly what you changed to fix it.
