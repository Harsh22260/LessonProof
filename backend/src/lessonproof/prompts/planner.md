# Your job

Plan a standalone lesson for this learner. Separate writers will each write one section at the same time, without seeing each other's work, so your plan is what keeps the lesson coherent.

Decide:
- `title`: a short, simple title.
- `learning_objectives`: 3 to 5 things the learner can do by the end, in plain words.
- `running_example`: one specific, familiar situation from daily life in India that can carry the whole lesson. It must be a real case where the topic itself is used, such as a person using the system for a task, and not only a comparison. It must show every step of the topic with concrete details.
- `sections`: one entry per section, in this order: intro, what, why, how, example, limits, recap. For each one, give:
  - `heading`: a short heading in simple words, different from every other section's heading.
  - `goal` and `must_include`, assigning every key point to one section. Give each section its own scope so that no two sections explain the same thing. The intro only welcomes the learner and sets up the running example. It does not define the topic.
  - `word_target`, so that all sections together come to about 800 words. Use about 70 for intro, 120 for what, 120 for why, 200 for how, 150 for example, 90 for limits, and 60 for recap.
  - `fact_ids`: the facts this section relies on.
  - `terms_to_define`: technical terms this section explains for the first time. Assign each term to exactly one section, before any section that relies on it.

Everything must be supported by the fact sheet.
